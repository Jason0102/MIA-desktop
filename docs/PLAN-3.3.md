# MIA 3.3 開發計畫（待審核，尚未實作）

日期：2026-11-17。此分支目前只保存規劃，不代表任何項目已實作或獲准開發。

## 版本目標

- 3.1：高互動性的桌寵介面。
- 3.2：Hermes 整合的多用途個人助理。
- 3.3：具有互動記憶與持續心情，能依對話情境調整表達的個人化助理。

核心流程：互動事件 → 每日／每週記憶 → 持續心情 → 結合當下對話 → 情緒標籤 → 文字、動畫、語音。
長期個性、持續心情、當句情緒分開管理。

## 開發項目

1. **統一互動紀錄（必要）**：保存使用者、來源管道、時間、事件類型、對話／任務識別與時長。統計非任務發話及聊天段數、閒聊話題及可信度、新任務／續接／完成／失敗／取消、游標靠近／停留／點擊／摸頭／拖曳、陪玩場次／投球次數／有效時長、明確回饋與陪伴時間。同人 PC／Discord 可合併或分開查看，不同使用者隔離。混合訊息可多類標記，但總發話數不重複。
2. **計數規則（必要）**：聊天輪次與段落分開，段落暫以閒置 10 分鐘切分，待實測調整。游標事件去抖及冷卻；使用者陪玩與自主玩球分開。鎖屏、休眠、暫停不累加有效時長；異常退出依最後有效紀錄結算。訊息重送、同步、工具重試及子任務不算新指派。
3. **每日／每週記憶（必要）**：今日、本週、近 7 天、近 30 天統計；按使用者時區切日，預設週一起算，跨午夜拆分時長。產生日／週摘要、常見話題及習慣變化，摘要保留事件來源。歷史缺少的資料標記未知，不補造數據。
4. **MIA 後台資訊頁（必要）**：以 HTML 製作進階資訊頁，在 MIA 的設定分頁加入「後台資訊」連結，點擊後另開頁面。HTML 沿用主介面的主題色、字體、圓角、間距及按鈕樣式。頁面包含互動概況與日／週趨勢、話題及偏好修正、心情維度及成因，以及每句情緒標籤所對應的動畫與語音。使用者亦可透過對話詢問米亞目前的心情。
5. **持續心情模型（必要）**：愉悅度、活力、親近感、玩心四維。角色基準加近期有效互動加權及緩慢長期趨勢，隨時間回歸基準。相同事件邊際遞減並限制每日影響；親近感慢變、活力及玩心快變。工作完成也屬正向共同經驗；少互動或大量派工不造成懲罰。初期規則可解釋、權重可調，資料不足用預設值。
6. **對話／動畫／語音整合（必要）**：提供心情快照、相關記憶與偏好；當句內容決定最終情緒，持續心情為參考。沿用現有標籤及動畫建立映射，三種表達共用結果。保留拖曳、掉落、停靠、任務與語音優先順序；語音失敗仍有文字及動畫。語速、停頓與說話力度的標籤控制見第 9 項。
7. **完整記憶重置（必要）**：清除該使用者的對話、長期記憶、互動事件、統計、話題摘要、已儲存的偏好、親近感、心情歷史、共同回憶、相關快取及衍生索引。回復角色初始心情，保留角色基本設定、服務設定與工作成果。PC／Discord 同步更新記憶版本，防止舊會話及在途請求寫回；部分失敗不得宣稱全部成功。
8. **資料管理及驗收（必要）**：本機保存為主，模型僅取所需摘要；可停用記錄、刪除話題、修正偏好及設定保存期限。事件、摘要及心情計算解耦，不為游標事件逐次呼叫模型。驗收跨日週、重啟、休眠、連點、自主玩球、去重、使用者隔離與重置不回流。
9. **ElevenLabs v4 語音表達控制（待審核）**：米亞依持續心情與當下對話情境，搭配既有情緒標籤選用語速、停頓及說話力度的標籤。例如解釋複雜步驟時用 `[slowly]`，轉換話題時用 `[pause]`，晚間輕聲陪伴時用 `[softly]`。以米亞的聲線試聽，確認各標籤的效果及與情緒標籤搭配時的自然度。這些標籤引導語音演繹，實際效果依聲線和上下文而異。

## 建議順序與審核範圍

- A 規格：定義事件、計數、心情與記憶重置範圍。
- B 記憶與後台：第 1–4、7–8 項，驗收記錄、統計及重置。
- C 情緒與語音：第 5–6、9 項，驗收心情連續性，以及動畫與語音表達的一致性。
