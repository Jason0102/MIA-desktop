# 公開內容與資料邊界

公開內容包括目前 C# 源碼、檢查程式、最終動畫圖集、HTML 動畫預覽、示範 MP3、建置／啟停腳本與文件。

不包含本機金鑰、個人 Voice ID 設定、對話／設定儲存檔、克隆來源錄音、舊發佈封裝、測試工作目錄及個人化角色原文。公開 role.json 改成可編輯的通用角色設定。

`api_key.example` 的兩個欄位均為空白；請複製為已被忽略的 `api_key` 後自行填入。公開程式的一般服務測試僅使用明確標記 fake／mock 的假資料。

動畫示範音訊已作為離線預覽收錄；它們不是 API 憑證，也不提供取得相同雲端聲線的權限。圖像及聲音素材尚未指定對外再利用授權。
