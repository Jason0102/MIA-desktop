MIA 3.2 功能待實作清單
更新日期：2026-11-16
狀態：以下七項已由使用者選定，尚未實作。27 為新增項目。
完成並驗證後將 [ ] 改為 [x]，補上完成日期與驗證結果。

[ ] 1. 排程任務與定時提醒
    接入 Hermes cronjob，支援建立、查詢、修改、暫停、恢復與刪除。
    支援單次及重複排程、時區、持久保存與重啟後恢復。
    將執行結果與提醒接到米亞文字／語音，處理錯過時間與重複通知。
    驗證：單次、重複、取消、重啟、休眠恢復及失敗情況。
    範圍：未選定獨立背景常駐；若程式退出，須明確說明不會準時提醒。

[ ] 4. 瀏覽器操作
    接入 Hermes browser，提供導覽、點選、輸入、擷取與下載能力。
    配置瀏覽器連線、登入狀態與操作權限，將成果回傳米亞。
    驗證：真實瀏覽器導覽、表單輸入、下載與取消流程。

[ ] 7. 持久工作看板 Kanban
    接入 Hermes 看板與調度，支援排隊、依賴、阻塞、審核與交接。
    與既有工作中心對接，保留任務狀態及歷史，避免重複派工。
    驗證：依賴順序、失敗／阻塞恢復、審核及重啟後狀態。

[ ] 8. 程式化工具編排
    接入 Hermes code_execution，以 Python 組合工具與批次工作。
    明確限制執行環境、檔案／網路權限、逾時及取消行為。
    驗證：多工具組合、部分失敗處理、取消及結果回傳。

[ ] 9. MCP 外部工具接入
    提供 MCP 服務設定、連線狀態、工具發現、授權及停用流程。
    逐項確認服務相容性，將工具結果整合進米亞任務。
    驗證：連線、工具呼叫、服務中斷、憑證失效與停用。

[ ] 12. Webhook 事件觸發
    接入外部事件接收、驗證、觸發規則及任務結果回報。
    處理重送去重、失敗重試與事件紀錄；外部內容不得作為權限指令。
    驗證：有效／無效事件、重送、執行失敗及結果通知。

[ ] 27. 個人行事曆與行程衝突檢查
    實作免費的 MIA 本機行事曆工具，以 SQLite 儲存事件。支援新增、查詢及修改，
    包含起迄時間、地點、時區、全天及重複事件。資料持久保存於 MIA 工作區，
    透過第 9 項 MCP 提供本機工具，無須雲端帳號或 API 金鑰。
    透過第 4 項瀏覽器操作開啟 Google Maps 網頁，在路線介面選擇交通方式，
    可用時輸入對應的出發日期與時間，讀取畫面上的估算，納入準備與緩衝時間。
    只操作一般網頁介面，不呼叫 Maps API 或網站內部端點。
    技能已建立於 MIA-desktop-3.2/integration/hermes/skills/mia-calendar/SKILL.md。
    工具接好後，將技能部署到 MIA 的 Hermes profile 並驗證可被對話觸發。
    驗證：新增與修改、重啟後保留事件、重複事件、時間重疊、前後交通不足、
    缺地點、查無路線，以及網頁無法設定指定出發時間。
    此項範圍為事件管理與衝突檢查，提前提醒暫緩。
